Los estudiantes podrán: Usar Micro:Bit y XGO para secuenciar comandos y depurar movimientos combinados para crear coreografías fluidas y comprender la autonomía expresiva y el diseño creativo.

🤖 Prompt de Referencia para XOLO (Solo para Maestro)

⚠️ NOTA: XOLO ya conoce el tema de esta misión. Este prompt es SOLO de referencia en caso de emergencia técnica: 
Quiero aprender a construir una secuencia completa de movimientos combinados para el XGO usando Python. Explícame primero qué significa secuenciar comandos y por qué el orden y los tiempos importan. Luego enséñame cómo coordinar xgo.roll(angle), xgo.pitch(angle) y xgo.translation(x,y,z) para crear una coreografía fluida. Guíame para construir una rutina en 4 fases: inicio (pose), transición (roll/pitch), desplazamiento (translation) y cierre (pose). Incluye cómo depurar si el robot se mueve brusco o se descoordina (ej: velocidad, pausas, ángulos). Termina con un reto: “crea una coreografía que parezca que el robot está contando una historia” y evalúame.

🚨 Resolución Rápida de Problemas

  • Si los alumnos no pueden ingresar a Gnius Space: Activa XOLO SOS en xolo.gnius.club para continuar la misión sin interrumpir la clase.
  • Si el robot no responde: Verificar que la batería esté cargada y bien conectada. Revisar que el micro:bit esté correctamente insertado.
  • Si el robot no se mueve correctamente: Confirmar que la extensión correspondiente esté instalada en MakeCode. Verificar que las articulaciones no estén bloqueadas.
  • Si el XGO se mueve de forma brusca: Revisa con XOLO los tiempos de pausa entre comandos y reduce los ángulos de movimiento.
  • Si hay errores en el código: Recordar a los estudiantes que XOLO puede ayudar a depurar. Pídeles que copien el error y se lo muestren a XOLO.

📊 Diapositiva 3: Brain Spark

1. 💬 Pide a XOLO que te ayude a crear:

"Ayúdame a idear una coreografía artística con el XGO usando Python sincronizada con música o ritmo. Quiero que combine movimientos, pausas y poses expresivas en una rutina de 20–30 segundos. Después genera el código en Python para el ejecutarlo, Luego dame el código en Python para ejecutarlo, de acuerdo a tu entrenamiento con el robot XGO y Micro:bit. incluyendo pausas exactas para que se sienta sincronizado."

2. 🔬 Experimenta y descubre con tu programa:

  • ¿El XGO completa todos los movimientos de la coreografía sin caerse?
  • ¿Qué pasa si reduces el tiempo de pausa entre un movimiento de 'roll' y uno de 'pitch'?
  • ¿Funciona igual la coreografía en una superficie lisa vs. una rugosa?
  • ¿Cómo lograste que el robot expresara una emoción específica a través de la autonomía expresiva?
  • ¿Qué restricciones de diseño creativo tuviste que superar para que la rutina durara 30 segundos?

¡Es hora de crear nuestra obra maestra! Vamos a idear una coreografía artística. Primero, definan con XOLO qué historia o 'vibe' quieren transmitir. Una vez que tengan su GCS, tradúzcanlo a bloques en MakeCode. Por ejemplo, podrían hacer que su XGO parezca un perrito emocionado que saluda y luego hace una pirueta. No olviden las pausas, son el secreto del ritmo. Prueben primero en el simulador y, cuando estén listos, pasen el código al robot real. Si algo no sale fluido o el robot se mueve raro, ¡pregúntenle a XOLO! Él los ayudará a depurar el código para que todo sea perfecto.
